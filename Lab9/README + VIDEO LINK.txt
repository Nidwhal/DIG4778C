README:

The way the design patterns were implemented into the game was by creating a builder for the ducks and constructing the ducks through the builder.
The observer pattern was implemented by creating an observer class that had a list of observers that can listen for changes in the score in order to adjust the score for the game.
The object pool pattern was implemented by creating a bulletPool class with the IObjectPool type. The bullets are taken and retrieved from the pool as needed.
